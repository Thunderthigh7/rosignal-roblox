# Security

RoSignal publishes its Roblox-side source so developers can audit what runs in Studio and inside their experience.

If you believe you found a security vulnerability, please avoid posting secrets, access tokens, pairing codes, game keys, private user data, or exploit details in a public GitHub issue.

Instead, contact RoSignal privately through the support/contact methods listed on https://rosignal.app.

Useful reports include:

- what component is affected;
- the behavior you observed;
- steps to reproduce it safely;
- the impact you believe it has;
- any suggested mitigation.

The hosted RoSignal backend is not part of this public repository.
